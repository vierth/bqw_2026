# EAS 328: Building Qianlong's World
This is the second iteration of this class, with the first being the version I taught at William & Mary in 2023. This repository will contain tools, code, and various other useful things for our various projects. Whenever I cannot easily include something in this repository, I will link to it here.

Everything here is a work in progress, and we are building this plane together as we are flying it. If you run into issues, send me a message and we can work through it. The Unreal Plugins I have developed are works in progress and I encourage you to fork them, expand upon them, and submit pull requests to add features. Feature requests are also welcome.

## Design philosophy (to be discussed in class)
It is not always clear from the map what direction a building is facing, and other aspects of the layout are sometimes ambiguous. We will need to discuss how to approach this and other ambiguous issues.

### Everything must be accessible.
There should be some way to access every space on the map. If there is not a clear entrance to an area provide one and make note of how you have deviated from what is shown on the map.
